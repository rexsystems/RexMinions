description: What RexMinions needs to start.
sidebar:
  order: 2
---

- Java 21
- Paper, Purpur, or Folia 1.21 or newer
- PlaceholderAPI 2.11 or newer, only if you want placeholders
- WorldGuard 7, only if you want region checks

The plugin shades its own SQLite driver. You do not install SQLite yourself. Placed minions are stored in `plugins/RexMinions/minions.db`.
